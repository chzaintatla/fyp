# Hosting the cloud brain on Render

Render runs only the **cloud brain** (`app/cloud_main.py`): planning, chat, speech-to-text and text-to-speech.
It cannot open apps or touch files on your Windows PC, so the AgentDesk app on your PC calls it and runs every
tool locally, re-checking each plan with its own safety rules. Your Groq keys live only on Render.

## Deploy
1. Push this repository to GitHub (the `render.yaml` Blueprint is at the repository root).
2. Render dashboard -> New -> Blueprint -> pick the repository. It creates the `agentdesk-cloud` web service.
3. In the service's Environment tab: set `GROQ_API_KEYS` (comma separated). `CLOUD_API_TOKEN` is generated by Render:
   copy its value.
4. Wait for the deploy; open `https://<your-service>.onrender.com/health` -> `{"status":"ok","keys":N,"token_set":true}`.

## Connect the Windows app
Add to `backend\.env` on your PC, then restart the app:

    CLOUD_BRAIN_URL=https://<your-service>.onrender.com
    CLOUD_BRAIN_TOKEN=<the CLOUD_API_TOKEN value>

With these set, the strict planner asks the cloud first (see `PLANNER_MODE` in docs/STATUS.md).

## Things to know
- Free instances sleep after ~15 minutes idle; the first request then takes 30-60 s. A paid instance stays awake
  (needed for the voice latency targets).
- Every request needs `Authorization: Bearer <token>`; without the token the server answers 401, and it refuses to
  serve at all (503) if `CLOUD_API_TOKEN` is shorter than 24 characters. Requests are limited per minute
  (`CLOUD_RATE_PER_MINUTE`, default 30).
- The Groq free tier allows 8,000 tokens per minute per organization; keys from the same organization share it.
- Nothing is stored on Render: no database, no logs of commands.
